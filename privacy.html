Personal OS 隐私政策

更新日期：2026 年 9 月 16 日

本政策说明 Personal OS 为提供个人任务、目标及日程管理功能而处理的数据。维护与联系邮箱：scut.david.lin@gmail.com。

访问的数据与用途

应用处理 Google 账号标识、邮箱及基础资料，用于登录和识别账户。Google Tasks 权限用于读取、创建、更新、整理及删除任务与任务清单；处理的数据包括标题、说明、日期和完成状态。Google Calendar Events 权限用于读取日程、检查时间冲突及管理任务日历投影，相关数据包括活动内容、时间及提醒。

存储与服务提供方

Google Tasks 是普通任务内容与完成状态的主数据源，Google Calendar 保存日程投影。Supabase 处理登录会话、加密保存的 Google 刷新凭证、排程元数据、目标与计划、每日小结以及操作审计。审计可能包含原始输入、语音转写文本、对话历史、任务变更前后信息、候选匹配与决策依据和操作结果。浏览器在本机保存 Supabase 登录会话凭证、任务与计划缓存，并在 OAuth 回调期间临时保存 Google 授权凭证，完成连接后清除临时凭证；GitHub Pages 托管静态网页。

使用已连接的 ChatGPT / MCP 时，相应请求和工具返回内容也会由该已授权服务处理，其处理方式受该服务政策与账户设置约束。相关服务在提供功能所需的范围内处理数据。

语音输入

启用语音输入时，麦克风内容由浏览器或设备提供的语音识别服务处理，其处理方式受相应平台规则约束。发送的转写文本可进入任务和对话审计记录；Personal OS 当前实现不保存原始录音。

使用限制

Personal OS 不出售 Google 用户数据，不将其用于广告定向或训练通用人工智能模型。Personal OS 对 Google API 信息的使用及向其他应用的转移遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保存、撤销与删除

用户可在 Google 账号的第三方连接设置撤销访问。撤销会停止后续 Google 数据访问，不会自动删除 Google Tasks / Calendar 中的已有内容，也不等同于删除 Supabase 中的元数据、审计或本机缓存。

你可以在 Google Tasks / Calendar 管理相应数据，并联系上述邮箱申请处理 Personal OS 存储的数据。账户及相关数据按提供功能所需保留，当前没有统一的自动清理期限，对话审计采用不可变记录，现有界面不支持逐条修改或删除；备份与服务提供方的保留规则可能另有适用期限。清除浏览器站点数据可移除本机缓存，但不会删除云端数据。

保护措施与政策更新

Google 刷新凭证在服务端加密保存，服务端权限限制凭证读取；网络请求使用 HTTPS。若数据用途或权限发生变化，本页面将更新，并在需要时重新取得授权。
